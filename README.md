# Sales Performance & Order Analysis

## Project Overview

This project analyzes sales orders to understand overall sales performance, order trends, profitability, customers, products, regions, and sales channels.

The analysis was performed using Microsoft Excel with supporting pivot tables and dashboard-based analysis.

## Objectives

- Analyze overall sales and revenue performance
- Understand order quantity trends over time
- Analyze sales and profit by product category
- Compare performance across sales channels
- Identify important customers and products
- Analyze regional and state-level sales performance
- Understand cost and profitability
- Create meaningful insights using pivot tables and dashboard visualizations

## Dataset

The dataset contains approximately 42,700 sales order records covering the period from 2014 to 2018.

### Key fields include:

- Order Number
- Order Date
- Ship Date
- Due Date
- Customer Name
- Channel
- Currency Code
- Warehouse Code
- Region
- Country
- State
- Product Name
- Product Category
- Order Quantity
- Unit Price
- Total Revenue
- Total Unit Cost
- Total Cost
- Profit
- Year
- Month Name

Additional supporting tables include:

- Customers
- Regions
- State Regions
- Products
- Multi Scenario

## Key Metrics

- **Total Revenue:** $809.73M
- **Total Cost:** $615.40M
- **Total Profit:** $194.34M
- **Total Order Quantity:** 360K+
- **Profit Margin:** 24%

## Analysis Performed

### Sales Channel Analysis

Sales performance was analyzed across:

- Wholesale
- Distributor
- Export

Wholesale generated the highest revenue among the analyzed channels.

### Product Analysis

Product categories were analyzed to identify categories contributing the most to total revenue and profit.

### Time-Based Analysis

Sales and order quantities were analyzed by:

- Year
- Month
- Order Date

This helped identify changes and trends in sales performance over time.

### Regional Analysis

Sales performance was analyzed across different regions and states to understand geographical performance.

### Profitability Analysis

Revenue, cost, and profit were compared to understand overall business profitability.

## Key Insights

- Wholesale was the largest sales channel by revenue.
- The business generated approximately $809.73M in total revenue.
- Total profit was approximately $194.34M.
- Overall profit margin was approximately 24%.
- Sales performance varied across product categories and regions.
- Year- and month-level analysis helped identify sales trends.

## Conclusion

This project demonstrates how Excel can be used to transform raw sales-order data into meaningful business insights through data preparation, pivot-table analysis, profitability analysis, and dashboard visualization.

The analysis can help businesses understand their sales performance, identify profitable areas, and make data-driven decisions.
